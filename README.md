# Torka

Repositorio de trabajo con skills de Claude Code para asesoría comercial en acabados para construcción.

## Skills

En `.claude/skills/` hay 10 skills comerciales instaladas desde la librería
[alirezarezvani/claude-skills](https://github.com/alirezarezvani/claude-skills) (MIT).

Cubren precio y empaquetado, política de descuentos, revisión de operaciones, licitaciones,
economía de canal, pronóstico de pipeline, alta de socios y redacción de propuestas.

Ver [`.claude/skills/README.md`](.claude/skills/README.md) para el detalle de cada una,
las advertencias de uso y cómo añadir más.

Se activan solas cuando la conversación lo pide. También puedes invocarlas por nombre,
por ejemplo: «usa deal-desk para revisar este descuento».
